# claude-command-cli

A Termux-first command-line assistant powered by:

- Cloudflare Workers
- NVIDIA Nemotron 3 Ultra
- GitHub automation
- Claude Code Chats

## GitHub Automation Commands

### Open Claude with this repo

warnetech gh-open "claude-command-cli"

### Push changes

warnetech gh-push "message"

### Pull updates

warnetech gh-pull
